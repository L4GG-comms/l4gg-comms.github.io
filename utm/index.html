Making the short links in Short.io

  1. In Short.io, choose the L4GG.org domain and create a new link.
  2. Paste the tracked page as the original URL.
  3. Set the short path to the short link name exactly as shown, capital letters included.
  4. Repeat for each channel, then click one of the new links to check it lands on the right page.

The naming rules

Channelutm_sourceutm_mediumShort link ends in
  • Tags: lowercase, full words, underscores between words. Abbreviations only go in short link names.
  • Short links: always on L4GG.org, words run together with capitals (RejectOvertonLI), no hyphens or underscores. SMS links get a friendly name of their own (40Min), never a channel code.
  • Destinations: always the full https://www. address of an L4GG page, never another short link. Some short links drop the tags if you chain them.
  • One name per campaign across every channel, so all the links group together in reports.
