    How this works, for anyone reviewing it
    • No AI, no internet. This is one web page. All of its code is in the page itself. The page's security settings (Content-Security-Policy: default-src 'none') tell the browser to block every outside connection, so the page cannot send what you paste anywhere, even by mistake. You can check this in your browser's developer tools under Network: nothing is sent when you paste or convert.
    • Formatting only. The converter reads bold, italic, underline, links, bullet levels and font sizes from what you paste, and rewrites them in the newsletter's house style (fonts, sizes, colors, spacing). It never adds, removes, reorders or rewords text. The one change it makes to links is removing the google.com/url?q= wrapper that Google Docs adds, so the link goes straight to the page it already pointed to.
    • It checks its own work. After converting, it reads the finished HTML back and compares every word, every link and every italic phrase with what you pasted. If anything differs, it shows a red warning with the exact spot.
    • It fails loudly. When it meets something it doesn't recognize (an image, highlighted text, a bullet with no title), it keeps the words, marks the line in yellow and tells you what to check. It doesn't guess silently.
    • What it leaves to you. The banner, date line, greeting, sign-off and footer stay in the Mailchimp template. Images are added in Mailchimp.
